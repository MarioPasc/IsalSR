Expression DAGs

Equation (1) presumes , and Definition 3.1 does not guarantee it: an arbitrary edge set may give a Pow node three in-neighbors, or one. Call an expression DAG when every operation node carries exactly as many in-edges as its arity, every Var node has in-degree zero, and every Const node has in-degree at most one. Evaluation is defined on expression DAGs and on no others: outside that class a Pow node has no base–exponent pair to read, so denotes no function. Every DAG a host solver produces is an expression DAG, because each operation node is wired to exactly its operand slots. Every statement below that mentions is read over this class.

7. The Host-Solver Interface

Theorems 3.13–3.15 quantify over labeled DAGs whose non-variable nodes are all reachable from a variable. Expression DAGs delivered by a host symbolic regression solver need not satisfy that condition, and the reason is structural rather than accidental. Every insertion token of creates a node together with a creation edge from the acting pointer, so a non-variable node of in-degree has no encoding: no satisfies when contains such a node, and D2S cannot emit it because no pointer can be placed on one of its in-neighbors. Every operation node consumes operands and therefore carries in-edges; Const is the sole exception, being an evaluation-neutral leaf, so host solvers deliver numeric constants as terminals with nothing pointing into them. One step at the interface supplies the missing edge.

What the reduction is, and what it is not

Each isomorphism class contains exactly distinct internal-node numberings, by the orbit-stabilizer theorem applied to the action of on numberings, and the canonical string collapses all of them onto one representative. That is a bound on the redundancy present in the representation. The empirical reduction factor counts only the duplicates a search actually encounters within its time budget, and is therefore a lower bound on what an unbounded search would expose. The two must not be conflated: measured is on UDFS and on Bingo, while at those expression sizes is astronomically larger.
