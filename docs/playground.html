Encoded String

Verify the round-trip property: decode a string to a DAG (S2D), encode it back (D2S), decode again, and confirm the result is isomorphic.

Presets
1. Decode: S2D(w)
2. Encode: D2S(D, x₁)
3. Decode again: S2D(w′)

This is the paper's central claim, run in your browser. Pick an expression, and every one of the k! ways of numbering its k internal nodes is enumerated. Each numbering is a genuinely different labeled DAG object, and greedy D2S reads that numbering — so it returns several different strings. The fast canonical string of Definition 3.8 returns one, on every numbering.

Fast canonical string

The playground implements S2D, greedy D2S and the fast canonical string exactly as Section 3 of the paper defines them, down to the 64-bit FNV-1a hash the 1-WL step uses — so a canonical string computed here is the string the library returns. See How It Works for the walkthrough.
