6.4 CONST Normalization

Definition 19 (CONST Creation Edge Normalization)

Constant nodes are leaf nodes whose evaluation is independent of their in-edges. However, for D2S reachability (every node must be reachable from the CDLL traversal), each CONST node requires at least one in-edge (its "creation edge").
