Expression DAGs as Canonical Strings

IsalSR encodes symbolic regression expression DAGs as instruction strings over a 31-token alphabet using a circular doubly linked list with two mobile pointers. The canonical string is a complete labeled-DAG invariant — achieving O(k!) search space reduction.

How It Works

Three steps from mathematical expression to canonical string representation.

1

Expression DAG

Start with a mathematical expression represented as a labeled directed acyclic graph. Each node carries an operation type (ADD, SIN, MUL, ...) and edges encode data flow.

2

CDLL + Two Pointers

A circular doubly linked list with two mobile pointers traverses the DAG, emitting labeled tokens that encode structure and node operations.

3

Canonical String

The lexicographically smallest shortest encoding is a complete labeled-DAG invariant. All k! equivalent node numberings map to one representative.

Extending IsalGraph

IsalSR extends the IsalGraph framework from unlabeled, undirected graphs to labeled directed acyclic graphs for symbolic regression.

IsalGraph

9-character alphabet for undirected simple graphs. Unlabeled nodes, no edge direction, no acyclicity constraint. Complete graph invariant for topology.

IsalSR

31-token alphabet for labeled DAGs. 14 operation types with arity constraints, directed edges with cycle detection, commutative encoding (SUB→ADD+NEG, DIV→MUL+INV). Complete labeled-DAG invariant for expressions.
